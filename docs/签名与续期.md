# 7 天掉签是怎么回事，怎么让它自己续上

## 一句话结论

免费 Apple ID 签出来的**描述文件（provisioning profile）只有 7 天**；你看到的「一年」是**开发证书**的有效期。

iOS 每次启动 App 校验的是描述文件，不是证书。所以证书还有一年，App 第 8 天照样打不开。这是 Apple 服务端的规则，改 App、改配置、改签名方式都绕不过去。

能做的只有一件事：**在过期前重新申请一份 7 天描述文件，覆盖安装**。覆盖安装不会丢沙盒数据（书架、进度、朗读位置都在）。

| 方案 | 电脑要用几次 | 谁来续签 | 成本 |

## 方案 A：SideStore（推荐，手机自己续）

原理：SideStore 用你自己的 Apple ID，在手机上直接向 Apple 申请新的 7 天描述文件并覆盖安装。它靠 `LocalDevVPN` 建立一个只在本机回环的 VPN，让系统服务以为在跟电脑通信。全程不经过第三方服务器。

### 一次性设置

1. **iPhone 开开发者模式**：设置 → 隐私与安全性 → 拉到底 → 开发者模式 → 打开 → 重启 → 确认。
2. **电脑装 iloader**：只从 <https://iloader.app> 或 GitHub `nab138/iloader` 下载（2026-10 的 2.4.0+ 版本）。macOS 自带 usbmuxd，不用装 iTunes。
3. **连线安装 SideStore**：USB 连 iPhone → 解锁并点「信任」→ 打开 iloader → 登录 Apple ID → 选设备 → `Install SideStore (Stable)`。
4. **iPhone 信任开发者**：设置 → 通用 → VPN 与设备管理 → 开发者 App → 选你的 Apple ID → 「允许并重启」（iOS 18 之前是「信任」）。
5. **装 LocalDevVPN**：App Store 搜 LocalDevVPN（发布者 Coxson Engineering LLC），打开并连接，允许 VPN 配置。
6. **让 SideStore 先给自己续一次**：打开 SideStore → 用同一个 Apple ID 登录 → My Apps → 点 SideStore 自己的 `7 DAYS` 计数 → 完成后它就能长期待在手机上了。

### 导入 iRead

1. 把 `dist/iRead.ipa`（124 MB）隔空投送 / 存到 iPhone 的「文件」。
2. SideStore → My Apps → 右上角 `+` → 选这个 IPA。
3. 装完打开即可。bundle id 是 `com.yingyang.iread`，以后覆盖安装都会保留数据。

### 以后每周做什么

连上 Wi-Fi → 打开 LocalDevVPN 保持连接 → 打开 SideStore → My Apps → 点各 App 的剩余天数。

**别赌后台自动刷新**：SideStore 确实会尝试后台续签，但 iOS 会杀它的后台任务，官方 FAQ 也把「定期手动点一下」列为可靠做法。**5～6 天点一次**最稳。

### iOS 26.4 之后的额外一步

从 iOS 26.4 起，只带 lockdown 记录的旧配对文件会报连接/注册错误，需要 **remote pairing（RPPairing）**：

- 用 2026 年 10 月之后的 iloader 生成配对文件（新版一份文件里同时含两种记录）。
- SideStore → Settings → Pairing File Management → 长按 `Remote Pairing` → **Set as Preferred** → 重启 SideStore。
- 系统升级或抹机后配对文件会失效，需要再用一次电脑重新生成。

### 免费账号的硬限制

- 同一台设备**最多 3 个**已签名 App（SideStore 自己占 1 个）。
- 每周最多注册 10 个不同 App ID。
- 描述文件固定 7 天，没有「永久签名」这种东西。

### 已经掉签了怎么办

图标变灰或点开闪退时，**数据还在**，只是签名失效：

- 能打开 SideStore → My Apps 刷新 iRead；
- 打不开 SideStore → 用 iloader 重装 SideStore，再装同一个 `com.yingyang.iread` 覆盖；
- 电脑在手边 → 直接 `./scripts/install-device.sh`，一样是覆盖安装。

## 方案 B：Mac 自动刷新（不用 SideStore 时的兜底）

```bash
./scripts/auto-refresh.sh          # 手动跑一次
tail -30 ~/Library/Logs/iread-refresh.log
```

逻辑：每 6 小时检查一次 `embedded.mobileprovision` 的 `ExpirationDate`，**剩余不足 48 小时**才真正重新构建 + 覆盖安装。48 小时窗口里最多 8 次重试机会，又不会天天重装打断阅读。

- 定时触发用 WorkBuddy 的每日 09:00 任务（`launchctl bootstrap` 在本机被系统拦，报 `5: Input/output error`）。
- 前提：Mac 醒着，iPhone 连着（USB，或同一 Wi-Fi 下 `devicectl` 能发现）。
- 出门在外 Mac 不在身边时，这条路走不通 —— 这正是方案 A 存在的意义。

## 方案 C：付费开发者账号

$99/年，描述文件一年有效，不用任何续签折腾；要上 TestFlight 或 App Store 也只能走这条。

---

## 别再找「共享证书 / 企业证书 / 账号密钥」

- **企业证书**（$299/年）只允许分发给本公司员工，拿来签名公开 App 会被 Apple 吊销，届时所有装了的人都一起失效。
- 网上卖的「共享开发者账号」要你把设备 UDID 交给陌生人，对方随时能改密码、吊销证书，你的设备也会被一起拉黑。
- 免费账号不存在「永久签名」或「绕过 7 天」的漏洞。凡是这么宣传的，要么在骗钱，要么在拿你的账号冒险。

---

## App 里怎么看还剩几天

设置 → 关于 → **签名有效期**，直接读 `embedded.mobileprovision` 的到期时间；剩余 ≤2 天变橙色并提示去 SideStore 刷新。

（实现见 `iRead/Services/SigningHealth.swift`。沙盒里的 App 不能给自己重新签名，所以这里只做「看得见 + 提醒」，真正的续签必须在 App 外面完成。）
